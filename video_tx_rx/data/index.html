    移動偵測

    未設定區域
    DIFF --%

    在畫面上拖曳框選偵測區域：綠框 = 正常、紅框 = 偵測到移動。偵測在 ESP32 裝置端逐幀進行，關閉網頁仍持續監控；觸發時自動擷取影像存入「告警紀錄」（兩筆告警間隔至少 5 秒）。

    Discord 推播通知

    觸發告警時將「時間 + 擷取影像」傳送到 Discord 頻道，手機安裝 Discord App 並開啟通知即可收到推播。需先在「Wi-Fi 設定」連上可上網的網路。Webhook 建立方式：Discord 頻道 > 編輯頻道 > 整合 > Webhook。

    Telegram 推播通知

    觸發告警時將「時間 + 擷取影像」傳送到 Telegram 對話，手機安裝 Telegram App 即可收到推播。需先在「Wi-Fi 設定」連上可上網的網路。建立方式：跟 @BotFather 建立 Bot 取得 Token， 再向該 Bot 發一則訊息後用 Token 呼叫 getUpdates 取得你的 Chat ID。

    移動偵測告警

    每筆紀錄含觸發時間 + 觸發當下擷取影像，點選影像可開新分頁檢視原圖。 SD 模式（開機時插入 microSD）：存於 SD 卡 /alarms，保留最近 50 筆，斷電保留；TFT 模式：存於裝置記憶體，保留最近 10 筆，斷電或重新啟動後清空。

    播放器

    IDLE
    選擇下方錄影檔開始播放

    SD 卡錄影檔

    移動偵測觸發後自動錄影 2 分鐘（MJPEG-AVI，10fps，檔名 日期_時間_.avi），存於 SD 卡 /rec 資料夾，僅 SD 模式可用。檔案也可取出 SD 卡直接用電腦播放（VLC 等）。錄影進行中最新一筆檔案尚未完成，請等錄影結束再播放。

    OTA 無線更新

    上傳 Arduino IDE「Sketch > Export Compiled Binary」產生的韌體 .bin， 或 mkspiffs 打包的 SPIFFS 映像檔 (網頁資料)。更新完成後裝置會自動重新啟動。

    注意事項

    供電更新中請勿斷電
    分割區min_spiffs (含 OTA)
    影像串流更新期間自動暫停
    完成後裝置自動重啟，頁面自動重新整理

    登入保護

    啟用後，連上此裝置網頁需輸入帳號密碼才能存取（HTTP Basic Auth，瀏覽器原生登入視窗，儲存後請重新整理頁面登入）。使用者名稱留空並儲存可停用登入保護。忘記密碼需清除裝置儲存設定（NVS 或 SD 卡 appsetting.json）才能重設，請自行妥善保管。
